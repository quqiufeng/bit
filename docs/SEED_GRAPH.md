# Native seed graph

## Trusted root

```text
bootstrap/linux/seed.elf       (about 5 KiB, hand-written hex decoder)
bootstrap/linux/seed.hex       (reproduces seed.elf)
```

The only committed binary root is `seed.elf`.  A text-only root would move the
trust into the host shell or another decoder.

A0 and A1 are not committed as binaries.  They are materialized on demand from
their text seeds under a build or temporary directory:

```text
seed.elf < a0.seed.hex -> A0
A0       < a1.seed.hex -> A1
```

The reusable helpers are `bootstrap/linux/a0/from-hex.sh` and
`bootstrap/linux/a1/from-hex.sh`.

## Reproducible chain

```text
seed.elf
  + a0.seed.hex       -> A0 (materialized)
  + a1.seed.hex       -> A1 (materialized from A0)
  + c0v2.a1           -> C0v2
  + compiler-runtime.c-> native C1 (via C0v2 + A1)
  + standalone-*.c    -> c1l standalone linker (via C0v2 + A1)
```

The native script checks the fixed points:

- seed.elf reproduces itself from `seed.hex`
- A0 reproduces itself from `a0.seed.hex`
- A1 is produced by A0 from `a1.seed.hex`, and reproduces itself
- `C0v2(c0v2.c)` equals `c0v2.a1`
- native C1 stage1 equals stage2
- DDC: native C1 and gcc-built C1 produce identical compiler/runtime objects

## Seeds

| seed | form | regenerated by |
| --- | --- | --- |
| `seed.elf` | binary (trusted root) | `seed.hex` |
| `seed.hex` | hex text | seed root |
| `a0.seed.hex` | hex text | seed decoder |
| `a1.seed.hex` | hex text | A0 |
| `c0v2.a1` | A1 text | C0v2 fixed point |
| `compiler-runtime.c` | C text | `make-seed-source.sh` with `make-source.c` (optional) |
| `linux/standalone-*.c` | C source | source-built `c1l` linker |

The A0 and A1 binaries are derived build products, not seeds.  They are
regenerated by the `from-hex.sh` helpers whenever a script needs them.

## Not yet lowered

The first A0/A1/C0v2/linker images are still produced with the previous
generation tools.  They are verified fixed points, but their initial
provenance is the remaining formalization gap.

## Commands

```sh
bootstrap/linux/a0/from-hex.sh /tmp/a0.seed.elf
bootstrap/linux/a1/from-hex.sh /tmp/a1.seed.elf
BUILD=/tmp/zero ./build-zero.sh
BUILD=/tmp/core ./build-core.sh
bootstrap/linux/c0/native/make-seed-source.sh
tests/clean-room.sh
tests/clean-room-full.sh
```

`build.sh` additionally runs host-only PE, hosted glibc and interoperability
tests; it is not part of the zero-dependency core.
